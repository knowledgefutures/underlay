# ADAPT Centre Scraper

Tools for importing research data from the [ADAPT Centre](https://www.adaptcentre.ie) WordPress site into Underlay.

## Collections

| Collection     | Records | Schema Type    |
|----------------|---------|----------------|
| `team`         | ~392    | `researcher`   |
| `publications` | ~3,402  | `publication`  |

## Usage

### 1. Scrape data from ADAPT website

```bash
npx tsx tools/adapt/scrape.ts
```

This pulls all experts and publications from the WordPress REST API and writes structured JSON to `tools/adapt/data/`.

### 2. Set up Underlay target

1. Start the dev environment: `./dev.sh`
2. Create an `adapt` org (via dashboard or API)
3. Create an API key with write scope for the org

### 3. Push to Underlay

```bash
UNDERLAY_API_KEY=ul_xxx npx tsx tools/adapt/push.ts
```

The push script:
- Creates `adapt/team` and `adapt/publications` collections if they don't exist
- Pushes all scraped records as version 1
- Records are validated against JSON schemas in `schemas/`

### Data Source

All data comes from the ADAPT Centre public WordPress REST API:
- Experts: `GET /wp-json/wp/v2/experts`
- Publications: `GET /wp-json/wp/v2/publications`
- Taxonomies: `team`, `research-domains`, `journal_type`
